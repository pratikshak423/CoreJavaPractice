# Core Java Practice

This repository contains my daily practice questions and solutions for mastering **Core Java** concepts. It includes examples, exercises, and code snippets to reinforce my understanding of Java programming.

Each day contains:
1. Problem statements.
2. Java code solutions with comments for better understanding.

## Goals
- Strengthen Java implementation skills.
- Master object-oriented programming concepts.
- Build a strong foundation for advanced Java topics like JDBC, Collections, and Streams.

## Usage
1. Open the folder for a specific day to view the problems and solutions.
2. Run the code using any Java IDE (e.g., IntelliJ, Eclipse, VS Code) or the command line:
   ```bash
   javac Main.java
   java Main
   ```
